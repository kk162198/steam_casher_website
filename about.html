誰做的

一個人。沒有公司、沒有團隊、沒有投資人。這是我的個人專案。

抓資料的程式用 Python 寫，排在 GitHub Actions 上跑；網站是純靜態的 HTML，直接查資料庫，沒有後端伺服器。整套東西的月成本接近零，這也是它能免費的原因。

為什麼做

因為我自己要用。想買遊戲的時候，每次都要開好幾個分頁比對 CSFloat 和 Steam 的價格，再自己拿計算機扣手續費，很煩。

而且網路上講這件事的教學，幾乎都只給你帳面價差，不扣手續費。看起來 50%，實際做完剩 20% 出頭。這種數字會讓人做出錯誤的決定，我不想做成那樣。

所以這個網站有兩條原則：所有數字都是扣完手續費的實拿值；每個賣點旁邊都寫清楚對應的代價。金額太小的時候，它會直接告訴你不要用。

錢從哪裡來：沒有錢進來

完全免費。沒有付費方案、沒有廣告、沒有聯盟行銷連結、沒有推薦碼。

不抽成

你省下的錢全部是你的，我拿不到任何一塊。CSFloat 也沒有付我推薦費。

不碰金流

錢只在你和 CSFloat、Steam 之間流動。這個網站從頭到尾沒有任何收款或轉帳的功能。

不碰帳號

不要你的 Steam 密碼、不要 API key、不代你下單。任何要你交出帳號的網站都要小心，包括看起來像這個的。

沒有帳號系統

不用註冊，所以我沒有你的 email、沒有你的任何個人資料。你的勾選和作答只存在你自己的瀏覽器裡。

講這些不是為了顯得清高，是因為這件事牽涉到你的真錢和你的 Steam 帳號。你有權知道我從你身上拿不到任何東西，這樣你才有理由相信網站上的數字沒有被調整過。

如果哪天這個情況改變，例如加入贊助或推薦連結，我會寫在 更新日誌 的最上面，不會偷偷加。

我的立場

  • 這個網站只做資料整理與試算，不是投資工具，也不是理財建議。
  • 所有價格都是近即時的市場估算，不保證準確。下單前請自己核對一次。
  • 是否要做、做多少，決定權在你。後果也在你。
  • 如果你這次的情況不適合用，網站會直接告訴你，不會硬推。
