我們在做什麼

Steam 加值幫手是一個個人開發的資料整理工具，鎖定 CS:GO／CS2 武器箱在 CSFloat 與 Steam 社群市場之間的價差，把原本需要手動比對多個網站的繁瑣過程自動化：後端排程程式每隔一段時間抓取兩邊的最新報價，寫入資料庫；前端網站再把整理好的套利機會以清楚的表格與試算工具呈現出來，讓使用者可以用更低的實際花費取得 Steam 錢包餘額。

技術架構

資料抓取端使用 Python 撰寫，分別串接 CSFloat 的 listings API 與 Steam 社群市場的公開報價 API，統一寫入 Supabase 資料庫；其中 CSFloat 資料已透過 GitHub Actions 排程，每 3 小時自動更新一次。前端網站是純靜態頁面，使用 Tailwind CSS 做樣式，並透過 Supabase 的 JavaScript Client 以唯讀金鑰即時查詢資料庫，不需要額外的後端伺服器。

我們的立場

本工具只做資料整理與試算，所有的價格數據皆為即時或近即時的市場估算，不保證絕對準確，也不會替使用者執行任何交易、不會經手任何金流。是否購買、購買多少，最終決定權都在使用者自己手上，請務必自行評估風險，並詳閱各頁面中的使用注意事項。
