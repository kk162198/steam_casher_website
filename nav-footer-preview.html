預覽頁・不是網站的一部分

nav.html ／ footer.html

這頁用各頁面現有的 loadNav() / loadFooter() 做法載入兩個片段，行為與正式頁面一致。 把瀏覽器縮到 768px 以下可以看漢堡選單與全螢幕覆蓋。

接上頁面時要做的事

  • 兩個片段自帶 <style>，會覆蓋容器上舊的 bg-slate-800／bg-slate-950，各頁的 <nav> 與 <footer> class 不用改。
  • 片段內的 <script> 用 innerHTML 插入不會執行，所以漢堡選單一律用 inline onclick，不依賴頁面 JS。
  • 導覽列的資料狀態點預設是中性灰。有資料的頁面抓完資料後呼叫下面這段即可。
// assets/site.js 已經提供，各頁直接呼叫即可
setNavStatus('fresh', '資料 12 分鐘前更新');   // fresh | aging | stale

// 或直接丟資料的更新時間，讓它自己判斷三態
setNavStatusFromTime(item.csfloat_updated_at, 'csfloat');

頁面高度用這段文字撐開，方便看 sticky 導覽列與頁尾。
