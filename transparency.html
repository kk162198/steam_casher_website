實拿倍率怎麼算

這是全站所有數字的基礎。兩邊的手續費都在公式裡，沒有藏起來的部分。

手續費率

項目 費率 誰付 說明
CSFloat 買方手續費 約 7.5% 你 已含在網站顯示的「CSFloat 成本」裡。
Steam 市場手續費 15% 你（依賣家淨額計算） 含 5% Steam 手續費與 10% CS2 遊戲手續費，兩者都是對賣家淨額計算。

兩個手續費分量各有 US$0.01 的最低收費，所以低價品項的實際費率會高於 15%；換算到賣價上，一般品項的實際抽成約 13%。網站顯示的數字已經照 Steam 的實際計算方式算過。

完整算式

# 1. 你在 CSFloat 實際付出的成本（每件） # # 掛牌價之外還要付 7.5% 的買方手續費。 # csfloat_cost = csfloat_掛牌價 × (1 + 0.075) # 2. 你在 Steam 賣掉之後實際收到的金額（每件） # # steam_price 是買家付的錢，不是你拿到的錢。 # # Steam 的 5% + 10% 手續費是對「賣家淨額」計算， # 不是對賣價計算： # # 買家付的錢 = 賣家淨額 × 1.15 # # 所以從賣價反推淨額要用「除的」，不是乘 0.85。 # steam_income = steam_price ÷ (1 + 0.15) # 3. 稅後淨利（每件） # # 賣掉一件實際多拿多少，兩邊手續費都扣完了。 # diff = steam_income − csfloat_cost # 4. 實拿倍率：花 1 元換到多少 Steam 餘額 # # 低於 1 代表這個品項現在做會虧錢。 # ratio = steam_income ÷ csfloat_cost # 5. 換算成折扣：買同一款遊戲便宜幾 % # # 網站上顯示的「便宜約 N%」就是這個數字。 # discount = (1 − 1 ÷ ratio) × 100%

帶一組數字進去

# 已知條件（這兩個數字是從市場抓來的） # csfloat_掛牌價 = NT$ 93 steam_price = NT$ 152 # 1. 你在 CSFloat 要付多少 # csfloat_cost = 93 × 1.075 = NT$ 100 # 2. 你在 Steam 賣掉實際拿到多少 # steam_income = 152 ÷ 1.15 = NT$ 132 # 也就是說，買家付的 152 元裡， # Steam 抽走 20 元（約佔賣價 13%）。 # 3. 這一件實際賺多少 # diff = 132 − 100 = NT$ 32 # 4. 花 1 元換到多少餘額 # ratio = 132 ÷ 100 = 1.32 # 5. 換算成折扣 # discount = (1 − 1 ÷ 1.32) × 100% = 約 24%

帳面上 93 元的東西賣 152 元，看起來是 63% 的價差。扣完兩邊手續費之後，你實際的折扣是 24%。網站上顯示的一直都是後面這個數字。
